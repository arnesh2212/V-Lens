# V-Lens results package

- `results.tex` - Results (about 2.6 pages) and a combined Discussion and conclusion. Section labels: sec:results, sec:res-method, sec:res-data, sec:discussion (also sec:conclusion).
- `appendix.tex` - the full appendix: "Further results" (full-length main-text results and the figures that did not fit), then protocols and per-experiment detail. Include after `\appendix`.
- `setup.tex` - the experimental setup (models, dataset summary matching the SimonSays section, baselines, metrics); label sec:exp-setup, which results.tex cites.
- `figures/` - every figure the three files use (paths are `figures/...`).
- `refs_user.bib` - the authors' collected bibliography; `refs_extra.bib` - the attribution and method entries supplied later. All citation keys used are in these two files.
- `main.tex` / `main.pdf` - a wrapper that compiles the package on its own (tectonic or pdflatex + bibtex).

Tables are inlined (generated by tools/make_paper_tables.py and tools/make_appendix_tables.py, then tools/flatten_paper.py).
